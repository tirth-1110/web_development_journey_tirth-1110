# 📄 05 — Introduction to HTML

## 🧭 What this lesson covers
A minimal first HTML file introducing the language itself — no tags beyond the bare essentials.

## 📁 File
[`introduction.html`](./introduction.html)

## 🏗️ Structure
-  `<!DOCTYPE html>` and `<html lang="en">` — standard document declaration and language attribute
-  `<head>` — contains only a `<title>` (no charset or viewport meta tags yet)
-  `<body>`
  -  `<h1>` — page heading: "Introduction to HTML"
  -  `<p>` — one paragraph defining HTML as HyperText Markup Language, the standard markup language for structuring web content

## 🔑 Key concepts introduced
-  Basic HTML document skeleton (`html`, `head`, `body`)
-  Heading tag (`h1`)
-  Paragraph tag (`p`)
-  What HTML is and what it's used for (conceptual, not yet code-heavy)

## 🚧 Not yet covered here
-  `<meta charset="UTF-8">` / viewport meta tags
-  Additional heading levels, lists, links, images
-  Any styling or attributes beyond `lang`

## ▶️ How to view
Open `introduction.html` directly in any browser — no build step or dependencies required. 🌍
