# 🎓 My Web Development Learning Journey

Welcome to my repository tracking my progress through **CodeWithHarry's Ultimate Web Development Course** on Udemy. This repository acts as my personal learning hub where I store all my practice code, exercises, and mini-projects.

---

## 📝 About This Repository
This space is a structured digital notebook for my coding files. As I watch the course videos and follow along with Harry's instructions, I build out individual folders for different topics—starting from basic HTML structures all the way up to full-stack applications using Node.js, Express, and MongoDB.

---

## 🚀 How This Repository Helps Me

Building and keeping this repository updated helps me in three major ways:

*   **Hands-on Practice & Backups:** Instead of just watching video tutorials passively, this repository forces me to write, test, and save my own code. It keeps my practice assignments safely backed up in the cloud.
*   **Tracking Growth & Consistency:** The green squares on my GitHub contribution graph provide visual motivation to code consistently. Over time, looking back through these files helps me see exactly how much my coding skills have improved.
*   **Building a Future Portfolio:** Sharing my course code here helps me get comfortable with Git workflows early on. When I am ready to apply for junior developer roles or internships, this repository stands as proof of my dedication and programming habits.
