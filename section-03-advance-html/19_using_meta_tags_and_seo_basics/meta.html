Meta Tags

Meta tags are used to provide metadata about a web page. They are not displayed on the page itself but are used by search engines and browsers to understand the content and context of the page.

They go inside the <head> element of an HTML document.

This website is a simple example of a web page with meta tags and SEO basics.

Common Meta Tags

  • Meta Charset: Specifies the character encoding for the HTML document (e.g., UTF-8).
  • Meta Description: Provides a brief summary of the page's content. Search engines often display this description in search results.
  • Meta Keywords: A list of keywords relevant to the page's content. Note: This tag is largely ignored by modern search engines.
  • Meta Viewport: Controls the layout on mobile browsers, ensuring the page is responsive.
  • Meta Author: Specifies the author of the page.
  • Meta Refresh: Automatically refreshes the page after a specified number of seconds. Or can be used to redirect users to another page after a few seconds.

SEO Basics

Search Engine Optimization (SEO) is the practice of increasing the quantity and quality of traffic to your website through organic search engine results.

  • Title Tag: The title of your page, which appears in search engine results and browser tabs. It should be unique and descriptive.
  • Meta Description: As mentioned above, this should be a concise summary of your page's content and include relevant keywords.
  • Header Tags (H1, H2, etc.): Use heading tags to structure your content and make it easier for search engines to understand the hierarchy of your page.
  • Semantic HTML: Use appropriate HTML elements to convey meaning and structure to your content, making it more accessible and understandable to search engines.
  • Viewport Meta Tag: Controls the layout on mobile browsers, ensuring the page is responsive.
