Iframes and Embedding Content

Iframes allow you to embed another HTML page within the current page. <iframe> tag is used for this purpose.

Some Important attributes of iframes

Attribute Description
src Specifies the URL of the page to embed.
width, height Specifies the width and height of the iframe.
frameborder Specifies whether to display a border around the iframe.
allowfullscreen Allows the iframe content to be displayed in fullscreen mode.
loading="lazy" Specifies how the iframe should be loaded (e.g., lazy loading).

Security Note: Some websites may block iframe embedding for security reasons using headers like X-Frame-Options.
