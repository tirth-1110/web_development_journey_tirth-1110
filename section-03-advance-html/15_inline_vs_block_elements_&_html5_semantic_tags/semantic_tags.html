Inline Elements

Inline elements do not start on a new line and only take up as much width as necessary. Usually used to style small portions of content within block elements.

Common Inline Elements

  • <span> - Used to group inline elements for styling purposes.
  • <a> - Used to create hyperlinks.
  • <img> - Used to embed images.
  • <strong> - Used to indicate strong importance, typically displayed in bold.
  • <em> - Used to indicate emphasis, typically displayed in italics.
  • <code> - Used to display code snippets.
  • <br> - Used to insert a line break.

Block Elements

Block elements start on a new line and take up the full width available. Can contain other block and inline elements.

Common Block Elements

  • <div> - Used to group block elements for styling or layout purposes.
  • <h1> to <h6> - Used for headings, with <h1> being the highest level and <h6> the lowest.
  • <p> - Used to define paragraphs.
  • <ul> and <ol> - Used to create unordered and ordered lists, respectively.
  • <table> - Used to create tables.
  • <form> - Used to create HTML forms.

Semantic Tags

Semantic tags provide meaning to the structure of a webpage, making it more accessible and SEO-friendly.

Common Semantic Tags

  • <header> - Used to define the header of a page or section.
  • <nav> - Used to define the navigation links of a page.
  • <main> - Used to define the main content of a page.
  • <article> - Used to define an independent piece of content.
  • <section> - Used to define a section of a page.
  • <aside> - Used to define content that is tangentially related to the main content.
  • <footer> - Used to define the footer of a page or section.
