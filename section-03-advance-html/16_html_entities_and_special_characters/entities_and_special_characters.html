Entities and Special Characters

In HTML, certain characters have special meanings and cannot be used directly in the content. To display these characters, we use HTML entities.

Common HTML Entities:

  • & - Ampersand (&). "&amp;" is used to display an ampersand in the content.
  • < - Less than (<). "&lt;" is used to display a less-than sign in the content.
  • > - Greater than (>). "&gt;" is used to display a greater-than sign in the content.
  • " - Double quote ("). "&quot;" is used to display a double quote in the content.
  • ' - Single quote ('). "&apos;" is used to display a single quote in the content.
  • © - Copyright symbol. "&copy;" is used to display a copyright symbol in the content.
  • ® - Registered trademark symbol. "&reg;" is used to display a registered trademark symbol in the content.
  • ₹ - Rupee symbol. "&#8377;" is used to display a rupee symbol in the content.
  • → - Right-pointing arrow. "&rarr;" is used to display a right-pointing arrow in the content.
  • ← - Left-pointing arrow. "&larr;" is used to display a left-pointing arrow in the content.
  • ↑ - Up-pointing arrow. "&uarr;" is used to display an up-pointing arrow in the content.
  • ↓ - Down-pointing arrow. "&darr;" is used to display a down-pointing arrow in the content.
  •   - Non-breaking space. "&nbsp;" is used to display a non-breaking space in the content.
