Forms

Forms are used to collect user input. They consist of various input elements such as text fields, checkboxes, radio buttons, submit buttons, password, etc.

<form> tag is used to create an HTML form.

Different types of input types:

  • text
  • password
  • email
  • number
  • checkbox
  • radio
  • submit
  • reset
  • button

Placeholder text attribute is used to provide a hint or example of the expected input.
