Tables

Tables are used to display data in a structured format. Tables consist of rows and columns, and are created using the <table> element. <tr> elements define the rows, and <td> elements define the cells within each row. <th> elements define the header cells within each row.

By default, tables have a no border. border attribute is used to add a border to the table.

Table headings vs. table data

Table headings are typically used to define the purpose of each column in the table. They are displayed in a bold font and are usually placed in the first row of the table. Table data cells contain the actual information to be displayed in the table.

Spanning columns and rows

Use the colspan and rowspan attributes to span (merge) cells across multiple columns or rows.
