Lists

There are three types of lists in HTML:

  1. Ordered lists
  2. Unordered lists
  3. Description lists

Ordered List

Ordered lists are used to display a list of items in a specific order.

ol tag is used to create an ordered list.

This is an example of an ordered list:

  1. Chikoo
  2. Apple
  3. Mango

Types of Ordered Lists

There are three types of ordered lists in HTML:

  1. Numbered List
  1. Uppercase Alphabetical List
  1. Lowercase Alphabetical List

Unordered List

Unordered lists are used to display a list of items in no particular order.

ul tag is used to create an unordered list.

This is an example of an unordered list:

  • Chikoo
  • Apple
  • Mango

Types of Unordered Lists

There are three types of unordered lists in HTML:

  • Disc List. type="disc" attribute is used to create a disc bullet.
  • Circle List. type="circle" attribute is used to create a circle bullet.
  • Square List. type="square" attribute is used to create a square bullet.

Description List

Description lists are used to display a list of terms and their corresponding descriptions.

dl tag is used to create a description list.

dt tag is used to define a term in a description list.

dd tag is used to define the description of a term in a description list.

Here is an example of a description list:

Chikoo
A tropical fruit with a sweet taste.
Apple
A common fruit that grows on trees.
Mango
A juicy fruit with a distinctive flavor.

Nested Lists

Lists can be nested inside other lists.

It means you can have a list inside another list. It can be ordered list inside unordered list or unordered list inside ordered list or description list inside another description list or description list inside ordered list or description list inside unordered list or unordered list inside description list or ordered list inside description list.

Here is an example of a nested list:

  1. First level item
    • Second level item
    • Second level item
  2. First level item
    • Second level item
    • Second level item
  3. First level item
    • Second level item
    • Second level item
