# 📄 06 — Headings and Paragraphs

## 🧭 What this lesson covers
Demonstrates all six HTML heading levels and how the `<br>` tag forces a line break inside a paragraph.

## 📁 File
`headings_and_paragraphs.html`

## 🏗️ Structure
-  `<!DOCTYPE html>` and `<html lang="en">` — standard document declaration and language attribute
-  `<head>` — contains only a `<title>` (no charset or viewport meta tags yet)
-  `<body>`
  -  `<h1>` through `<h6>` — all six heading levels, each labeled by number
  -  `<p>` — a single paragraph using `<br>` twice to create line breaks within it

## 🔑 Key concepts introduced
-  The full heading hierarchy (`h1` = largest/most important → `h6` = smallest)
-  Paragraph tag (`p`)
-  Line break tag (`br`) — forces a new line without starting a new paragraph

## 🚧 Not yet covered here
-  `<meta charset="UTF-8">` / viewport meta tags
-  Semantic use of headings (e.g., one `h1` per page, nesting order for accessibility/SEO)
-  Multiple separate `<p>` tags instead of `<br>` for paragraph spacing
-  Any styling or attributes beyond `lang`

## ▶️ How to view
Open `headings_and_paragraphs.html` directly in any browser — no build step or dependencies required. 🌍
