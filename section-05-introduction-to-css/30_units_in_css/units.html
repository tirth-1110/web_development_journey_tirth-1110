Units in CSS

CSS units define the size, spacing, and positioning of the elements on a web page. Understanding units is essential for building layouts that are consistent, responsive, and easy to manage.

Two Categories of Units

  1. Absolute Units

    These do not change based on screen size or parent element. Use them for fixed size elements (use cautiously in responsive designs).

    Unit Description
    px Pixels (most common absolute unit)
    pt Points (1/72 of an inch)
    cm Centimeters
    mm Millimeters
    in Inches

    Examples:

    
.px {
    font-size: 30px;
}
            
    
.pt {
    font-size: 15pt;
}
            
    
.cm {
    font-size: 1cm;
}
            
    
.mm {
    font-size: 10mm;
}
            
    
.in {
    font-size: 1in;
}
  2. Relative Units

    They are responsive and scale based on parent element, root font size, or viewport size.

    Unit Description
    % Relative to parent element
    em Relative to parent's font size
    rem Relative to root font size (usually <html>)
    vw 1% of viewport width
    vh 1% of viewport height
    vmin 1% of smaller viewport dimension
    vmax 1% of larger viewport dimension

    Examples:

    
.percentage {
    width: 70%;
}
            
    
.em {
    font-size: 2em;
}
            
    
html {
    font-size: 16px;
}

.rem {
    font-size: 2rem;   /* 32px */
}
            
    
.vw_vh {
    width: 80vw;    /* 80% width of the viewport */
    height: 80vh;   /* 80% height of the viewport */
}
            
    
.vmin {
    font-size: 2vmin;
}
            
    
.vmax {
    font-size: 2vmax;
}

Commonly Used Units

px (pixels)


.px {
    margin: 30px;
}

Fixed spacing that does not scale with screen size.

% (percentage)


.percentage {
    width: 70%;
}

Useful for making widths and heights relative to parent elements.

em vs rem

em: Relative to the font size of the parent.


.em {
    font-size: 2em;   /* 2 times the parent's font size */
}

rem: Relative to the font size of the root (html) element.


html {
    font-size: 16px;
}

.rem {
    font-size: 2rem;   /* 32px */
}

Use rem for consistency in modern responsive designs.

vw and vh


.vw_vh {
    width: 80vw;    /* 80% width of the viewport */
    height: 80vh;   /* 80% height of the viewport */
}

These units are powerful for creating fullscreen layouts.

calc() Function

Combine different units using calc().


.calc {
    width: calc(100% - 200px);
}

Best Practices

  • Use rem for typography for consistency and scalability.
  • Use %, vw, vh for responsive layouts.
  • Avoid overusing px in responsive designs.
