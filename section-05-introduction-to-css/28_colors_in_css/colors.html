Colors in CSS

Colors plays a major role in the visual appearance of a website. In CSS you can apply colors to text, background, borders, and other elements using different formats.

Ways to define Colors.

CSS supports several formats for defining colors.

  1. Named colors

    CSS has a set of predefined color names like red, blue, green, orange, yellow, etc.

    h1 {
    color: red;
}
  2. HEX codes

    A hexadecimal value represents a color using a six-digit code.

    body {
    color: #00ffff;
}

    Some common HEX Codes:

    • #000000 → Black
    • #ffffff → White
    • #ff0000 → Red
    • #00ff00 → Green
    • #0000ff → Blue

    You can also use shorthand if all pairs are the same:

    #fff /* same as #ffffff */
#000 /* same as #000000 */
#f00 /* same as #ff0000 */
#0f0 /* same as #00ff00 */
#00f /* same as #0000ff */
  3. RGB (Red, Green, Blue)

    You can define a color using RGB color model.

    p {
    color: rgb(255, 0, 0);
}
    • Values range from 0 to 255
    • rgb(0, 0, 0) → Black
    • rgb(255, 255, 255) → White

  4. RGBA (RGB + Alpha)

    Adds opacity to RGB using alpha channel (0=transparent, 1=opaque).

    div {
    background-color: rgba(0, 0, 0, 0.5);
}

    This creates a semi-transparent (translucent) black background.

  5. HSL (Hue, Saturation, Lightness)

    Another way to define colors using:

    • Hue (color angle on the color wheel)
    • Saturation (intensity of the color)
    • Lightness (brightness)
    h2 {
    color: hsl(240, 100%, 50%);
}
  6. HSLA (HSL + Alpha)

    Same as HSL, but with transparency.

    section {
    background-color: hsla(240, 100%, 50%, 0.5);
}

Applying colors in CSS

You can use color properties in many different ways.

h1 {
    color: navy;                    /* Text color */
    background-color: #e0e0e0;      /* Background color */
    border: 2px solid #333;         /* Border color */
}

Transparent and currentColor

  • Transparent → Makes an element's color fully transparent.
  • currentColor → Inherits the current value of the color property.
button {
    color: blue;
    border: 2px solid currentColor;
}
