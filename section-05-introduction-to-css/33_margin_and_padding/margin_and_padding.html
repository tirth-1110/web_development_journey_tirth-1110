Margins And Paddings

Margin and Padding are two of the most commonly used properties in CSS to control spacing around elements. They are part of the CSS Box Model and play a crucial role in layout and visual structure.

Padding vs Margin

Property Affects Where the spaces appear
Padding Inside the element Between the content and the border of the element
Margin Outside the element Between the border of the element and adjacent elements

Padding

Apply space inside the border, around the content.


.padding {
    padding: 20px;
}

This adds 20px space inside all four sides of the .padding.

Individual Sides


.padding_sides {
    padding-top: 10px;
    padding-right: 15px;
    padding-bottom: 20px;
    padding-left: 25px;
}

Shorthand


.padding_shorthand {
    padding: 10px 15px 10px 15px; /* top right bottom left */
    padding: 10px 15px; /* top-bottom | right-left */
    padding: 10px; /* all sides */
}

Margin

Adds space outside the border of the element.


.margin {
    margin: 20px;
}

This adds 20px space outside all four sides of the .margin.

Individual Sides


.margin_sides {
    margin-top: 10px;
    margin-right: 0;
    margin-bottom: 20px;
    margin-left: auto;
}

Shorthand


.margin_shorthand {
    margin: 20px 40px 20px 40px; /* top right bottom left */
    margin: 20px 40px; /* top-bottom | right-left */
    margin: 0 auto; /* top-bottom: 0, left-right: auto (used for centering) */
}

Auto Margin (Horizontal Centering)

When you set the left and right margins to auto, the browser calculates the margins equally, centering the element horizontally within its container.


.auto_margin {
    margin: 0 auto;
}

This centers the container horizontally if a fixed width is set.

Margin collapse

When two vertical margins meet (e.g., margin-bottom of one element and margin-top of the next), the larger one wins, not their sum.


.margin_collapse_1 {
    margin-bottom: 30px;
}

.margin_collapse_2 {
    margin-top: 20px;
}

The space between the two elements will be 30px, not 50px.
