Typography in CSS

Typography is how text appears on a webpage - its font, size, spacing, alignment, weight, and overall readability. Good typography improves user experience and design quality.

Basic Text Properties

  1. font-family

    Sets the typeface for your text.

    .font-family {
    font-family: Arial, sans-serif;
}
    • You can specify a list of fallback fonts.
    • Always end with a generic family like sans-serif, serif or monospace.

    Common font stacks:

    font-family: "Helvetica Neue", Helvetica, Aerial, sans-serif;

    font-family: Georgia, 'Times New Roman', serif;

    font-family: 'Courier New', Courier, monospace;
  2. font-size

    Controls the size of the text.

    .font-size {
    font-size: 30px;
}

    You can use units like px, em, %, rem.

  3. font-weight

    Defines the boldness of the text.

    .font-weight {
    font-weight: lighter;
}

    You can use keywords like bold, normal, lighter, or numerical values like 100, 400, 700, 900.

  4. font-style

    Sets text to normal, italic, or oblique.

    .font-style {
    font-style: oblique;
}
  5. text-align

    Aligns text horizontally.

    .text-align {
    text-align: center;
}

    Values: left, right, center, justify

  6. line-height

    Controls the space between lines of text.

    .text-height {
    text-height: 2;
}
  7. letter-spcing

    Controls space between characters.

    .letter-spacing {
    letter-spacing: 5px;
}
  8. word-spacing

    Controls space between words.

    .word-spacing {
    word-spacing: 10px;
}
  9. text-transform

    Changes the case of text.

    .uppercase {
    text-transform: uppercase;
}
    .lowercase {
    text-transform: lowercase;
}
    .capitalize {
    text-transform: capitalize;
}
  10. text-decoration

    Controls underlining, Overlining, and line-through.

    .text-decoration {
    text-decoration: line-through;
}

Using Google fonts

To use custom fonts, you can load them from Google Fonts.

HTML:

<head>
    <title>Google Fonts</title>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Caacupe+One&display=swap" rel="stylesheet">
</head>

CSS:

.google_font {
    font-family: "Caacupe One", sans-serif;
    font-weight: 400;
    font-style: normal;
}
