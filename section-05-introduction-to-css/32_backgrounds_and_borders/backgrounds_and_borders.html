Backgrounds and Borders

CSS allows you to customize how elements look and feel by adding backgrounds and borders. You can apply colors, images, gradients, and control borders precisely around elements.

Background Properties

  1. background-color

    Sets a solid color behind an element.

    p {
    background-color: lightblue;
}
  2. background-image

    Adds an image as the background of an element.

    p {
    background-image: url('Manga-Portal.png');
}

    You can use local images or remote URLs for background images.

  3. background-repeat

    Controls how a background image is repeated.

    p {
    background-repeat: repeat; /* Default*/
    background-repeat: no-repeat;
    background-repeat: repeat-x; /* Repeats horizontally */
    background-repeat: repeat-y; /* Repeats vertically */
}
  4. background-size

    Specifies the size of the background image.

    p {
    background-size: cover; /* Cover the entire element */
    background-size: contain; /* Scale the image to fit */
    background-size: 100px 200px; /* Width and height */
}
