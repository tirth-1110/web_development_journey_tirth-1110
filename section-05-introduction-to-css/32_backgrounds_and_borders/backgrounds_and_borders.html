Backgrounds and Borders

CSS allows you to customize how elements look and feel by adding backgrounds and borders. You can apply colors, images, gradients, and control borders precisely around elements.

Background Properties

  1. background-color

    Sets a solid color behind an element.

    p {
    background-color: lightblue;
}
  2. background-image

    Adds an image as the background of an element.

    p {
    background-image: url('Manga-Portal.png');
}

    You can use local images or remote URLs for background images.

  3. background-repeat

    Controls how a background image is repeated.

    p {
    background-repeat: repeat; /* Default*/
    background-repeat: no-repeat;
    background-repeat: repeat-x; /* Repeats horizontally */
    background-repeat: repeat-y; /* Repeats vertically */
}
  4. background-size

    Specifies the size of the background image.

    p {
    background-size: cover; /* Cover the entire element */
    background-size: contain; /* Scale the image to fit */
    background-size: 100px 200px; /* Width and height */
}
  5. background-position

    Controls the position of the background image within an element.

    p {
    background-position: center; /* Center the image */
    background-position: top; /* Align to the top */
    background-position: bottom; /* Align to the bottom */
    background-position: left; /* Align to the left */
    background-position: right; /* Align to the right */
    background-position: top right; /* Align to the top right */
    background-position: top left; /* Align to the top left */
    background-position: bottom right; /* Align to the bottom right */
    background-position: bottom left; /* Align to the bottom left */
    background-position: 50px 100px; /* X and Y offsets */
}
  6. background-attachment

    Determines whether the background image scrolls with the page or stays fixed.

    p {
    background-attachment: scroll; /* Default */
    background-attachment: fixed; /* Stay fixed */
}
  7. Shorthand Property:background

    Combines all background properties into one line.

    p {
    background: url('Manga-Portal.png') no-repeat center/cover fixed;
}

Border Properties

  1. border-width

    Sets the width of the border.

    p {
    border-width: 5px; /* Sets all sides to 5px */
    border-width: 5px 10px; /* Top/Bottom 5px, Left/Right 10px */
    border-width: 5px 10px 15px; /* Top 5px, Right/Left 10px, Bottom 15px */
    border-width: 5px 10px 15px 20px; /* Top 5px, Right 10px, Bottom 15px, Left 20px */
}
  2. border-style

    Specifies the style of the border.

    p {
    border-style: solid; /* Solid line */
    border-style: dashed; /* Dashed line */
    border-style: dotted; /* Dotted line */
    border-style: double; /* Double line */
    border-style: groove; /* 3D grooved line */
    border-style: ridge; /* 3D ridged line */
    border-style: inset; /* Inset line */
    border-style: outset; /* Outset line */
    border-style: none; /* No border */
}
    p {
    border-style: dashed;
}
    p {
    border-style: dotted;
}
    p {
    border-style: double;
}
    p {
    border-style: groove;
}
    p {
    border-style: ridge;
}
    p {
    border-style: inset;
}
    p {
    border-style: outset;
}
    p {
    border-style: none;
}
  3. border-color

    Sets the color of the border.

    p {
    border-color: red; /* Sets all sides to red */
    border-color: red blue green yellow; /* Top, Right, Bottom, Left */
}
  4. Shorthand Property:border

    Combines border-width, border-style, and border-color into one line.

    p {
    border: 2px solid red; /* Width, Style, Color */
}
  5. Individual Side Properties

    You can set borders for each side of an element individually.

    p {
    border-top: 1px solid red; /* Top border */
    border-right: 2px dashed blue; /* Right border */
    border-bottom: none; /* Bottom border */
    border-left: 3px dotted green; /* Left border */
}
  6. border-radius

    Rounds the corners of an element's border.

    p {
    border-radius: 10px; /* Rounds all corners */
    border-radius: 10px 20px; /* Top-left and bottom-right corners */
    border-radius: 10px 20px 30px; /* Top-left, top-right, bottom-right corners */
    border-radius: 10px 20px 30px 40px; /* Top-left, top-right, bottom-right, bottom-left corners */
}

    You can also use percentages for border-radius to create circular shapes.
